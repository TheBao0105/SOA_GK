API Docs

Hệ thống gồm 4 service độc lập, mỗi service có database riêng và giao tiếp với nhau qua HTTP/REST. Trang web này cũng chỉ gọi REST API của các service, không kết nối trực tiếp tới database nào. Identity Service cấp JWT; các service khác tự xác minh chữ ký bằng khóa công khai. Khi bật JWT_CHECK_ACCOUNT_STATE, service gọi thêm Identity để kiểm tra trạng thái tài khoản.

Trạng thái bên dưới chỉ kiểm tra HTTP 200 của /api/schema/. Đây chưa phải xác nhận database hoạt động. Khi service đang chạy mà SQL Server lỗi, trang này vẫn có thể báo API phản hồi.
